## 기억 저장소 (Hindsight)

세션 시작 컨텍스트에 "기억 저장소 (Hindsight)" 절이 있으면 그 폴더의 은행·저장 토큰·프로젝트 요약·최근 기억(3건)이 들어 있다. 최근 기억에 적힌 지난 결정은 존중하고, 뒤집을 때는 이유를 밝힌다. "프로젝트 요약"은 서버가 기억에서 자동으로 만든 글이라, 최근 기억이나 프로젝트 파일과 어긋나면 그쪽을 따른다.

- "세션 종료" / "세션 엔드" / "session end" → 진행 문서(PROGRESS·PLAN 등)가 있으면 먼저 정리하고, `/memory-save`로 인계문을 저장한다.
- "기억해" → `/memory-save note`, "잊어줘" → `/memory-save forget`, "정정해" → `/memory-save correct`.
- 자동 중간 저장 기준: 설계를 바꾸는 결정, 되돌리기 어려운 선택, 재현하기 어려운 함정. 셋 중 하나가 나오면 사용자가 말하지 않아도 `/memory-save note`로 저장한다. 일상 진행 상황은 저장하지 않는다.
- 명령은 `~/.claude/scripts/hindsight-mem`이고, 저장·삭제는 주 세션이 직접 한다. 보조 에이전트는 기억을 저장하지 않으며 저장 토큰을 받지 않는다.
- 저장 금지: 실명, 주민번호, 급여, 연락처, 후보자 정보, 토큰·키·비밀번호는 쓰지 않는다.
- 저장 토큰이 없거나 저장이 실패해도 한 줄로 알리고 하던 작업을 이어 간다.

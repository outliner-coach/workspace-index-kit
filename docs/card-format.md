# 카드 형식과 규칙

카드는 `catalog/<name>.md` 한 장이고, 프로젝트 하나를 설명한다. 같은 프로젝트가 여러 컴퓨터에 있어도 카드는 한 장이다. 빈 카드는 `catalog/_template.md.txt`를 복사해 쓴다.

## 문법 (어기면 check가 ERROR)

- 파일 첫 줄 `---`, 다음 `---`까지가 머리부. 그 아래가 본문.
- 한 줄에 `key: value` 하나. 들여쓰기·중첩·여러 줄 값 금지.
- 값은 스칼라(따옴표 없음) 또는 인라인 리스트 `[a, b]`(빈 리스트 `[]`). 항목 안에 쉼표·대괄호 금지.
- `#`으로 시작하는 줄만 주석. 값 뒤에 붙인 `# …`는 값의 일부로 읽힌다.
- 14개 키 전부 필수. 모르는 키는 오류.
- `name`은 `^[a-z0-9][a-z0-9-]*$`이고 파일명과 같다. 날짜는 `YYYY-MM-DD`.
- 본문 제목은 정확히 `## 한눈에`, `## 들어갈 때 읽을 것`, `## 주의`, `## 관련 폴더` 이 순서.
- 한글은 NFC로 쓴다. CRLF 줄끝은 오류다.
- `catalog/` 안의 `*.md`는 전부 카드로 읽힌다. 카드가 아닌 md를 거기 두지 않는다.

이렇게 좁힌 이유: 외부 YAML 라이브러리 없이 표준 라이브러리만으로 확실하게 읽기 위해서다.

## 필드

| 필드 | 부류 | 뜻 |
|---|---|---|
| `name` | 고정 | 식별자. 폴더가 옮겨져도 **바꾸지 않는다**(기억 은행 이름이 곧 name) |
| `path` | 기록 | 기본 맥에서 작업공간 루트 기준 경로. 깊이 1, 또는 `bundle_dirs` 아래 깊이 2. 기본 맥에 없으면 `-` |
| `group` | 판단 | `config.json`의 `groups` 중 하나. 지도가 이 순서로 표를 나눈다 |
| `status` | 판단 | 아래 7값 |
| `summary` | 기록 | 한 줄 요약. 지도에 그대로 실려 라우팅 단서가 된다 |
| `stack` | 기록 | 기술 스택 |
| `entry_docs` | 기록 | 들어갈 때 읽을 파일, **읽는 순서대로** |
| `covers` | 판단 | 이 카드가 대신 설명하는 폴더(옛 클론·worktree·사본). 기본 맥 기준 |
| `related` | 기록 | 관련 카드 name |
| `aliases` | 기록 | 한글명·영문명·약칭·하위 프로젝트명. 요청 키워드를 여기에 맞춘다 |
| `sensitive` | 판단 | `none` · `credentials` · `pii` |
| `read_scope` | 판단 | pii일 때 읽어도 되는 하위폴더(필수) |
| `last_activity` | 자동 | build가 git 마지막 커밋 날짜(없으면 파일 수정 시각)로 쓴다. 손으로 적지 않는다 |
| `last_verified` | 기록 | 카드를 실제 폴더와 대조한 날. 들여다보지 않고 올리지 않는다 |

기록용은 에이전트가 조용히 고치고, 판단 필드는 고친 뒤 사람에게 한 줄로 알린다.

## status 7값

| 값 | 뜻 |
|---|---|
| active | 진행 중 |
| paused | 멈춤, 재개 가능 |
| done | 완료·유지보수만 |
| superseded | 다른 폴더가 대체. 본문에 후속 카드를 적는다 |
| template | 템플릿·참고용 |
| scratch | 실험·잡동사니 |
| removed | 모든 컴퓨터에서 폴더가 사라짐. 카드는 지우지 않고 남긴다 |

## sensitive 3값

- `pii`: 실명·주민번호·급여·고객·후보자 정보가 실제로 있는 폴더. `read_scope` 밖은 아무도 열지 않는다.
- `credentials`: `.env*`, `credentials/`, `secret*`, `private/`, `*.pem` 같은 파일이 있는 폴더. 본문 "주의" 절에 **파일명만** 적는다(값은 절대 적지 않는다).
- `none`: 그 외. 그래도 비밀 자료 금지는 그대로 적용된다.

## 폴더의 역할

스캔 범위 = 작업공간 루트 바로 아래 + `bundle_dirs`(기본 `work`, `personal`) 바로 아래. 숨김 폴더, `secret`, 이 저장소는 뺀다. 모든 폴더는 컴퓨터마다 셋 중 **정확히 하나**여야 한다.

1. **정본**: 어느 카드의 위치(기본 맥 `path`, 다른 맥 위치표)
2. **비정본**: 어느 카드의 `covers`(다른 맥 위치표의 "정본이 아닌 폴더")
3. **카드 없는 폴더**: `excluded.md`(다른 맥 위치표의 "카드 없는 폴더")에 사유와 함께

어디에도 없으면 "미등록 폴더" ERROR, 둘 이상이면 ERROR.

## config.json

```json
{
  "default_machine": "main",
  "groups": ["업무", "사이드 프로젝트", "생활", "학습·실험"],
  "bundle_dirs": ["work", "personal"]
}
```

- `default_machine`: 카드 `path`·`covers`와 `excluded.md`가 가리키는 컴퓨터 이름. 컴퓨터 이름은 작업공간 루트의 부모 폴더 이름이다(`/Users/alex/ai` → `alex`). 컴퓨터가 하나뿐이면 그 이름을 적는다.
- `groups`: 지도의 표 순서이기도 하다. 바꾸면 카드의 `group`도 함께 바꾼다.
- `bundle_dirs`: 하위 폴더까지 스캔하는 묶음 폴더. 묶음 폴더 자신은 `excluded.md`에 "묶음 폴더"로 적는다.

## 위치표 `machines/<맥>.md`

기본 맥이 아닌 컴퓨터의 위치. 표 세 개, 머리글은 정확히 아래와 같고 표 사이에 빈 줄을 둔다. 셋째 칸 `비고`는 사람용 메모다. 예시는 `examples/machines/home.md`.

```
| 카드 | 경로 | 비고 |
| 폴더 | 정본 카드 | 비고 |
| 폴더 | 사유 |
```

`machines/` 안에는 위치표만 둔다. 기본 맥 이름의 위치표는 만들지 않는다(ERROR).

## PROJECTS.md

카드·excluded.md·위치표에서 build가 만드는 지도다. **손으로 고치지 않는다.** 고치면 check가 "생성 결과와 다름" ERROR를 낸다. 어느 컴퓨터에서 만들어도 같은 바이트가 나온다(`생성` 줄 제외).

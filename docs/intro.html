→ 프로젝트가 늘어도 세션은 가볍게
🧠
이어지게세션·컴퓨터를 넘어 기억
새 세션은 백지. 어제 결정·함정을 다시 설명
세션을 열면 지난 결정·함정·남은 일이 자동으로 들어온다
→ 카드 이름 = 기억 은행 이름
🛡️
안전하게경계가 정해져 있다
.env·개인정보 파일도 열 수 있다
열지 말 파일·읽기 범위를 위임에 명시. 루트는 코드를 만지지 않는다
→ 기억 저장은 주 세션만(토큰)
🔧
저절로지도가 낡지 않는다
손으로 쓴 목록은 금방 실제와 어긋난다
build가 지도를 만들고 check가 실제 폴더와 대조한다
→ 세션 열 때마다 자동 점검
